PHASE 3 — KARAKTER + MIXAMO HATTI
================================================================

3.1 Karakteri hazırla
    Yol A (hızlı): Quaternius Ultimate Modular Character'ı FBX olarak
                   Mixamo'ya yükle -> auto-rigger -> şef karakteri hazır
    Yol B (en hızlı): Mixamo'nun kendi hazır karakterlerinden birini seç
                      (prototip için fazlasıyla yeterli)
    ÖNERİ: Prototipte Yol B. Oyun tutarsa Yol A ile kendi şefini yap.

3.2 İNDİRME SIRASI — bu sıra önemli
    (1) Karakteri T-pose'da, "With Skin", format "FBX for Unity(.fbx)"
        -> Chef_Base.fbx
    (2) Her animasyonu "Without Skin", format "FBX for Unity(.fbx)"
        -> Anim_Idle.fbx, Anim_Walk.fbx, Anim_Run.fbx,
           Anim_CarryIdle.fbx, Anim_CarryWalk.fbx, Anim_Chop.fbx

    Neden "FBX for Unity": normal FBX Binary'de Mixamo karakteri Unity'ye
    100 kat büyük/küçük geliyor ve scale ile uğraşıyorsun. Bu seçenek onu
    çözüyor. Yine de import inspector'da Scale Factor'ü gözle doğrula.

    LOCOMOTION İÇİN "IN PLACE" İŞARETLE:
    Walk / Run / Carry Walk indirirken Mixamo'daki "In Place" kutusunu işaretle.
    İşaretlemezsen animasyonun kendi root motion'ı karakteri sürükler ve
    CharacterController/NavMeshAgent ile çakışır. Cooked Fast'teki
    NavigationAbility zaten agent ile hareket ettiriyor — aynı mantık.

    FPS: 30 yeterli. Keyframe Reduction: none (prototipte fark etmez).

3.3 Unity import ayarları
    Chef_Base.fbx:
      Rig -> Animation Type: Humanoid
      Rig -> Avatar Definition: Create From This Model
      Configure... ile kemik eşleşmesini bir kez göz kontrolü yap
      -> Bu avatar'ın adını not al (Chef_BaseAvatar)

    Anim_*.fbx (hepsi):
      Rig -> Animation Type: Humanoid
      Rig -> Avatar Definition: COPY FROM OTHER AVATAR -> Chef_BaseAvatar
      Animation sekmesi:
        - Loop Time: Idle, Walk, Run, CarryIdle, CarryWalk -> AÇIK
        - Loop Time: Chop -> duruma göre (loop'lu doğrama istiyorsan açık)
        - Root Transform Rotation: Bake Into Pose AÇIK, Based Upon: Original
        - Root Transform Position (Y): Bake Into Pose AÇIK
        - Root Transform Position (XZ): Bake Into Pose AÇIK  <- in-place için
      Loop match göstergesi yeşil değilse Loop Pose'u aç.

3.4 Prefab
    Chef_Base'i sahneye at -> Animator + CharacterController (veya NavMeshAgent)
    + kendi Player script'in -> Prefab olarak kaydet.
    Elde tutulan yemek için el kemiğinin altına boş bir "HandSocket" transform
    ekle. Cooked Fast'teki Plateau mantığı buraya birebir taşınır.


================================================================
PHASE 4 — ANIMATOR CONTROLLER
================================================================

4.1 Parametreler
    float Speed          (0 = idle, 1 = walk, 2 = run — normalize edilmiş hız)
    bool  IsCarrying
    trigger Chop

4.2 Katman yapısı

    BASE LAYER (mask yok, weight 1)
      |
      +-- [Locomotion] Blend Tree (1D, parametre: Speed)
      |       0.0 -> Idle
      |       0.5 -> Walk
      |       1.0 -> Run
      |
      +-- [CarryLocomotion] Blend Tree (1D, parametre: Speed)
              0.0 -> Carry Idle
              1.0 -> Carry Walk

      Geçişler: Locomotion <-> CarryLocomotion, koşul IsCarrying
      Has Exit Time: KAPALI (elinde tabak varken anında geçmeli)
      Transition Duration: 0.15 sn civarı

    ACTION LAYER (Avatar Mask: sadece üst gövde, Blending: Override)
      |
      +-- [Empty] (boş state, weight 0 gibi davranır)
      +-- [Chopping]
      Geçiş: Empty -> Chopping (trigger Chop)
             Chopping -> Empty (Has Exit Time açık)
      Layer weight'i kodla 0'dan 1'e yumuşat, ya da sabit 1 bırakıp
      Empty state'i base ile aynı pozda tut.

    NEDEN İKİ KATMAN: doğrama sırasında karakterin bacakları hâlâ
    idle/walk oynasın istiyorsun. Tek katmanla yaparsan doğrarken
    yürüyemez.

4.3 Avatar Mask
    Assets > Create > Avatar Mask
    Humanoid bölümünde bacakları ve root'u KAPAT, gövde+kollar+kafa AÇIK.
    Action Layer'a ata.

4.4 Sık yapılan hatalar
    - Blend Tree eşiklerini raw m/s ile doldurmak: hız değişince bozulur.
      Speed'i her zaman 0-1 aralığına normalize et.
    - Transition Duration'ı 0 bırakmak: hareket robotik görünür.
    - Chop trigger'ını her frame set etmek: ResetTrigger'ı unutma.
    - Loop Time'ı açmayı unutmak: animasyon bir kez oynayıp donar.

PHASE 6 — VERTICAL SLICE HEDEFİ
================================================================

Prototipin "çalışıyor" sayılması için gereken minimum — TEK LEVEL:
  [ ] Şef karakteri joystick ile geziniyor, Idle/Walk/Run çalışıyor
  [ ] Bir malzemeyi alabiliyor -> Carry animasyonuna geçiyor
  [ ] Doğrama tezgahına yaklaşınca Chop tetikleniyor, malzeme dönüşüyor
  [ ] Doğranmış malzemeyi servis noktasına bırakabiliyor
  [ ] Ekranda bir sipariş görünüyor, doğru tabak gelince tamamlanıyor
  [ ] Süre doluyor, skor ve yıldız sayısı gösteriliyor

Bu altısı çalışınca elinde oyun var demektir. Öncesinde ses, menü,
level seçim ekranı, ilerleme sistemi ile uğraşma — hepsi bundan sonra.
